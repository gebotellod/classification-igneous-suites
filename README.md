### ESM2 — Full analysis pipeline

A single, self-contained Jupyter notebook covering the complete workflow described in the manuscript: data pre-processing, exploratory variable assessment and final dataset, and machine learning analysis.

Running it end-to-end creates four additional folders inside `ESM2/` (`Results/`, `Figures/`, `Imputation/` and `Plots/`) containing every table and figure generated by the notebook.

### ESM3 — Projecting new samples

Standalone notebook for projecting new geochemical samples from the Borborema Province onto the final trained SOM + K-means model developed in this study, assigning each sample to its corresponding geochemical cluster without requiring the full workflow in ESM2.

## Requirements

- **Python 3.11 or newer** (required by IntraSOM 1.1.2).
- The packages listed in [`requirements.txt`](requirements.txt).

IntraSOM is not published on PyPI at the version used here (1.1.2) and must be installed directly from its GitHub repository.

---

## Setting up the environment

### 1. Create and activate a virtual environment

**Using `venv` (Python's built-in tool):**

```bash
python3 -m venv venv

# macOS / Linux
source venv/bin/activate

# Windows (Command Prompt)
venv\Scripts\activate.bat

# Windows (PowerShell)
venv\Scripts\Activate.ps1
```

**Or using `conda`:**

```bash
conda create -n granites-esm python=3.11
conda activate granites-esm
```

### 2. Install the dependencies

```bash
pip install -r requirements.txt
pip install git+https://github.com/InTRA-USP/IntraSOM.git@v1.1.2
```

### 3. Register the environment as a Jupyter kernel (optional, recommended)

```bash
pip install ipykernel
python -m ipykernel install --user --name granites-esm --display-name "Python (granites-esm)"
```

When opening the notebooks in Jupyter, select this kernel from **Kernel → Change kernel**.

## Running ESM2 (full pipeline)

1. Open `ESM2/Granites_Full_Pipeline_FixedRandomState.ipynb` in Jupyter.
2. Confirm the raw data file is present at `ESM2/Dataset/Granites-DRN-Geochemistry.xlsx`.
3. Run the notebook from top to bottom (**Kernel → Restart & Run All**).

The notebook fixes a random seed at the start (`RANDOM_STATE = 42`) — do not modify this unless you intend to test result stability under a different seed.

---

## Running ESM3 (projecting new samples of Borborema Province)

1. Fill in `ESM3/Dataset/New_Samples_Template.xlsx` with your new samples (same columns: `Sample`, the 10 major oxides in wt%, and the 6 trace elements in ppm).
2. Open and run `ESM3/Granites_Project_New_Samples.ipynb` from top to bottom.
3. The resulting figure (`ESM3/Figures/`) shows each new sample's position on the trained U-matrix; `ESM3/Results/Projected_samples_BMU.xlsx` reports the same result as a table.

**Important:** trace elements and indices for new samples are standardized using the *exact* scalers fitted during ESM2's training (`trace_scaler.joblib`, `index_scaler.joblib`) — never refit on the new samples alone. Re-fitting on a small new batch would recenter it around its own mean and spread, a different coordinate system from the one the trained SOM actually learned, silently misplacing the projected samples on the map. See the note at the top of the ESM3 notebook for a worked example.
